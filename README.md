# CyberpunkDemo

This is a proof of concept of a character controller that simulates the movement of V from Cyberpunk 2077; it is **NOT** a complete project (the full "demo" is still a work in progress).<br>
Please see the dedicated portfolio page at: https://giovannigiacalone.com/CyberpunkMovement/

## Files

- CustomCharacterMovementComponent.cpp/.h
  - State Machine
  - Mantle/Vault
- States folder (inside there are all the various movement states)
- CustomCameraManager.cpp  

## Controls
- WASD         - Move
- Mouse        - Look around
- LEFT CONTROL - Dash
- SPACEBAR     - Jump/Double Jump
- SHIFT        - Run
- C            - Crouch
- ESC          - Quit application
